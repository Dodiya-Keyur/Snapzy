# Social Media Backend API

A simple backend API for a social media application similar to Instagram.

This project provides user authentication and post management using **Node.js, Express.js, MongoDB, and JWT**.

## Features

### Authentication
- User Registration
- User Login
- User Logout
- Change Password
- JWT Authentication
- HTTP-only Cookies
- Protected Routes

### Posts
- Create Post
- Get All Posts
- Get Logged-in User's Posts
- Get Post by ID
- Update Post
- Delete Post
- User information populated with posts

### User
- User profile management
- Get user information
- Update user information
- User's posts

## Technologies Used

- Node.js
- Express.js
- MongoDB
- Mongoose
- JSON Web Token (JWT)
- bcrypt
- Cookie Parser
- Multer
